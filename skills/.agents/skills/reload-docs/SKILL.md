# Reload Key Project Docs

After a context clear (or when requested), re-read the two primary project documents.

## Steps

1. Read these files in full:
   - `docs/tickets.md`
   - `GLOSSARY.md`

2. After reading both, briefly confirm:
   - How many open/active tickets you see (or the current state of the ticket list)
   - Any key terms or conventions from the glossary that are especially relevant right now

3. Do not load other markdown files unless the user specifically asks.

## Notes
- These two files are the source of truth for current work and terminology.
- Prefer reading them fully rather than summarizing unless they have grown very large.
