# AI-My-Skills

Custom Cursor skills I maintain.

These are skills I wrote for my own workflow. They are separate from the third-party skills in [AI-Project-Skills](https://github.com/MichaelB14/AI-Project-Skills).

## Skills

| Skill | Purpose |
|-------|---------|
| `sync-devops-tickets` | Sync open Azure DevOps work items into `docs/tickets.md` and keep project context so a new session can continue. |

## Install

From the project root:

```bash
npx skills add https://github.com/MichaelB14/AI-My-Skills
